# User Requirements

|ID|Description|
|--|--|
|1|Users must be able to provide budgetary values, along side descriptions, and an allotted frequency (Daily, Weekly, etc.)|
|2|User data must be stored securely|
|3|Users must be able to mark/check-off individual budget items, representing when that item has been paid/completed|
|4|Users must not be required to clone, copy or move items from one budgetary period to another- this must happen automatically|
|5|User experience is paramount, enabling the user(s) to spend as little time as possible within the application|
|6|Statistical calculations must be offered to the user(s)|
|7|Users must be able to input their budget for a given period|
