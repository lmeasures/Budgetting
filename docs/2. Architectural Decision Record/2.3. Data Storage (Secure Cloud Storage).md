# ADR-003: Data Storage (Cloud Storage)

## Status
Accepted

## Context
Users must have the option to sync their data to cloud storage. Application & User data must be stored securely in a cloud-based database.

## Decision
MongoDB Atlas

- 512 MB storage on the `Free` tier
- 5 GB storage on the `Flex` tier for 
  - $0.011/hr
  - $0.0264/day
  - $8.03/month
  - $96.36/year

## Alternatives
- DynamoDB (AWS)
- Google Cloud Firestore (Bigtable)
- Oracle NoSQL Database Cloud
- Azure Cosmos DB

## Consequences
- Upskilling is required in the use of MongoDB Atlas as a cloud service
- Additional considerations will need to be made with regards to ensuring data sent to MongoDB Atlast is encrypted
