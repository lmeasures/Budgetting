# ADR-001: Data Storage (Local Client Storage)

## Status
Accepted

## Context
Application & User data must be stored on the client device running the application. A decision must be made as to the best/most appropriate data storage facility/technology to be used.

## Decision
We will use IndexedDB in conjunction with the Storage MAnager API. 

> IndexedDB is the industry standard for client-side storage of large amounts of structured data, including files and blobs, offering gigabytes of space on both desktop browsers and mobile web views.

> To prevent the browser from automatically deleting data, you can request persistent storage using the Storage Manager API (navigator.storage.persist()). If granted, the browser will not evict data due to space constraints, though the user can still manually delete it.

## Alternatives
- Browser LocalStorage
- Device File Storage

## Consequences
- Upskilling on IndexedDB is required
- Data storage and retrieval will be fast
