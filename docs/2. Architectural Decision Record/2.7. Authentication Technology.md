# ADR-006: Authentication Technology

## Status
Accepted

## Context
An authentication technology & methodology must be selected which interfaces with a React frontend, and Express API backend.

This authentication technology must 
- be able to operate in 'local' mode, without a backing API or online database (as that functionality is out of scope for initial development)
- be usable on both Desktop web applications & Mobile web applications
- be able to interface to some degree with the selected Secure Cloud Storage option as per ADR-003

## Decision
Local passphrase with Key-Derived Encryption.
Using Argon2 / PBKDF2 / scrypt for encryption generation.

Flow
1. User creates a passphrase
1. Passphrase -> Argon2 / PBKDF2 / scrypt
1. Deribed key encrypts:
  - RxDB database
  - local metadata
1. On Login the passphrase decrypts the DB

## Alternatives
WebAuthn, Passkeys, Local Account w/ JWT

## Consequences
Later upgrades to cloud-based storage and synchronisation will require more work, however it will mean that initial implementation is exceedingly lightweight.
