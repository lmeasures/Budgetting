# ADR-004: API Technology

## Status
Accepted

## Context
A decision must be made to determine what technology will be used to develop the backend API.

The technology must be sufficiently advanced as to support multiple concurrent users and interface with the Secure Cloud Storage option as dictated in `ADR-003`

## Decision
Express API

## Alternatives
Fast API

## Consequences
API development and implementation will be very quick, and the API itself will be lightweight.
