# ADR-002: Data Security (Local Client Storage)

## Status
Accepted

## Context
Application & User data must be stored **securely** on the client device running the application. A decision must be made as to the best/most appropriate data storage facility/technology to be used.

## Decision
We will use RxDB.

> RxDB is a reactive, NoSQL database designed specifically for JavaScript applications (like React). It provides a reactive query interface, automatic encryption, and easy syncing with various backends, making it a powerful layer on top of IndexedDB.

## Alternatives
- PouchDB

## Consequences
- User data will be encrypted as standard
- Upskilling will be required on both IndexedDB and RxDB.
